# Attribution and redistribution notice

This directory combines and adapts code from the public FengWu inference and
training repositories:

- Inference: <https://github.com/OpenEarthLab/FengWu>
- Training: <https://github.com/yuchendoudou/FengWu>

The multi-accelerator runtime abstraction, FlagGems policy, portable launchers,
timing summaries, checkpoint policy and compatibility fixes in this directory
were added for this adaptation.

vendor SDK components are redistributed here. Those artifacts remain subject
